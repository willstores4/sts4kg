# Contributing

Thanks for helping improve NULL_store. Bug reports, suggestions, documentation improvements and code contributions are welcome.

## Report an issue

Describe what happened, what you expected, and the steps needed to reproduce it. Include your PS4 firmware and HEN version when relevant.

## Submit a change

1. For a substantial change, open an issue to discuss your idea.
2. Create a branch and keep your changes focused.
3. Run the relevant checks in [BUILDING.md](BUILDING.md).
4. Open a pull request describing your changes and how you tested them.
