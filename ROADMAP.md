# Roadmap

These ideas are planned improvements and are not yet available. Contributions and suggestions are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).

## Catalogue

- [ ] Add more filtering and sorting options.
- [ ] Group duplicate listings for the same game into a single entry.
- [ ] Let users choose between available download sources for a game.
- [ ] Improve game pages with descriptions, screenshots and trailers.
- [ ] Fix missing cover images for newly listed games.

## Downloads

- [ ] Explore premium account integration with Real-Debrid and AllDebrid.
- [ ] Show available seed and peer counts before downloading.
- [ ] Preview the files contained in a torrent before downloading.
